# Detektif_Bahasa
Teks Laporan Hasil Observasi  melalui konteks kearifan lokal kuliner Bandeng Presto.
🔎 Misi Detektif Istilah Teknis: Membongkar Rahasia Bandeng Presto

🔎 Tagline: "Cari Istilahnya, Pecahkan Misterinya, Jadilah Detektif Bahasa!"

Game pembelajaran interaktif berbasis web (Single Page Application) yang dirancang khusus untuk siswa Kelas VIII SMP pada mata pelajaran Bahasa Indonesia. Game ini membantu siswa memahami, mengidentifikasi, mengelompokkan, dan menganalisis Istilah Teknis (Kata Kajian) sebagai ciri kebahasaan utama dalam Teks Laporan Hasil Observasi (LHO) melalui konteks kearifan lokal kuliner Bandeng Presto.

🎯 Tujuan Pembelajaran (Capaian Pembelajaran)

Elemen: Membaca dan Memirsa / Kebahasaan Teks LHO.

Materi: Istilah Teknis / Kata Kajian Ilmu Pengolahan Pangan.

Indikator Ketercapaian:

Mengidentifikasi kata-kata yang termasuk istilah teknis dalam pengolahan Bandeng Presto.

Menemukan istilah teknis di dalam paragraf Teks LHO.

Membedakan antara istilah teknis (objektif/ilmiah) dengan kata umum/sifat subjektif.

Memasangkan istilah teknis dengan maknanya dan menganalisis pilihan kata berbasis HOTS (Higher Order Thinking Skills).

Mengaplikasikan istilah teknis dalam struktur kalimat yang tepat untuk memecahkan teka-teki Escape Room.

🎮 Fitur Utama Game

Gamifikasi Lengkap:

❤️ Sistem Nyawa: 3 Kesempatan (Lives).

⭐ Skor & Poin: +10 Poin per jawaban benar, -3 Poin jika salah, +20 Poin per level, +30 Poin bonus tanpa salah.

💡 Fitur Petunjuk (Hint): Konsumsi 5 poin untuk membuka petunjuk analisis detektif.

🔊 Web Audio Synthesizer (SFX): Efek suara dinamis untuk jawaban benar, salah, click, dan level up tanpa ketergantungan asset audio eksternal.

🎆 Canvas Confetti Effect: Efek animasi perayaan kemenangan saat menyelesaikan level.

5 Level Misi Berjenjang:

🟢 Level 1 — Kenalan dengan Bandeng Presto: Misi menangkap kata yang tergolong istilah teknis dari piring saji kuliner.

🔍 Level 2 — Buru Istilah Tersembunyi (Word Hunt): Misi mendeteksi dan mengklik kata teknis langsung dalam teks paragraf LHO.

🧪 Level 3 — Istilah Teknis atau Bukan? (Drag and Drop): Memilah kartu kata ke dalam keranjang "Istilah Teknis" atau "Bukan Istilah Teknis" (Dilengkapi dukungan Touch/Tap untuk perangkat seluler).

📖 Level 4 — Bongkar Teks LHO (Matching & HOTS): Memasangkan istilah dengan definisi ilmiahnya, dilanjutkan dengan tantangan analisis HOTS.

🔐 Level 5 — Escape Room Kode Rahasia: Menyelesaikan 5 teka-teki bahasa untuk mendapatkan 5 digit kode rahasia brankas detektif.

Sistem Feedback Edukatif:

Setiap pilihan jawaban memberikan penjelasan kontekstual (mengapa sebuah kata tergolong istilah teknis atau kata umum), bukan sekadar ucapan "Benar" atau "Salah".

Rapor & Gelar Detektif:

Menampilkan statistik akhir: Total Skor, Sisa Nyawa, Jumlah Istilah Ditemukan, dan Tingkat Akurasi.

Lencana Gelar:

🌱 Detektif Pemula (Skor < 100)

🔎 Detektif Muda (Skor 100 - 149)

⭐ Detektif Andal (Skor 150 - 199)

🏆 Detektif Bahasa Ahli (Skor ≥ 200)

🛠️ Teknologi yang Digunakan

HTML5: Struktur utama dan Canvas API untuk sistem efek partikel.

Tailwind CSS (via CDN): Desain UI modern dengan konsep Glassmorphism, responsif (mobile-friendly), dan ramah mata (Dark Mode Theme).

JavaScript (ES6+ Vanilla): Seluruh logika game, state management, interaksi drag-and-drop, dan alur kuis.

Web Audio API: Generasi efek suara synth (efek nada C-E-G untuk benar, nada gergaji untuk salah).

Font Awesome 6 & Google Fonts: Ikonografi dan tipografi interaktif (Inter & Fredoka).

🚀 Cara Menjalankan Game

Game ini bersifat Zero Dependency dan Single-File Native Application, sehingga tidak memerlukan proses build atau instalasi Node.js/npm.

Clone Repositori ini:
